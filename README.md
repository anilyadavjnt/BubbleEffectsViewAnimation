

# 🫧 BubbleEffectsViewAnimation – iOS App

An interactive iOS application built using **SwiftUI**, featuring beautiful bubble effects and smooth animations.

This project demonstrates creative UI development, animation techniques, and interactive visual experiences using SwiftUI.

## ✨ Features

- Beautiful Bubble Effects
- Smooth SwiftUI Animations
- Interactive UI Elements
- Creative Visual Experience
- Clean and Modern UI Design

## 🛠 Technologies Used

- Swift
- SwiftUI
- Xcode
- iOS Development
- SwiftUI Animations

## 🚀 Getting Started

1. Clone this repository.
2. Open `BubbleEffectsViewAnimation.xcodeproj` in Xcode.
3. Select an iOS Simulator or connected device.
4. Build and run the application.
